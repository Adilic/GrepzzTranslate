# Python 项目基础：读懂环境、文件和换电脑

这套教材讲 Python 项目共有的基础：代码由谁运行、包装在哪里、文件怎样分工、换电脑怎样恢复环境。学会这些方法，再做脚本、数据分析、网站或桌面程序都能用上；例子不依赖 GrepzzTranslate。

实验统一用 Python 3.12 和 Windows PowerShell，方便照着操作。这不表示所有项目都应选 3.12：实际项目先看它要求的版本和系统。部分命令也给出 macOS/Linux 写法。

   - 解释器、标准库、虚拟环境、激活、pip。
   - import、包、模块、运行入口、编辑器和 Notebook。
2. [第二册：怎样组织、维护和迁移一个项目](02-projects-and-reproducibility.md)
   - 文件结构、依赖声明与锁定、配置与数据。
   - 测试、日志、版本管理、构建与部署。
   - 同系统迁移、跨系统迁移、离线安装和工具选择。
3. [第三册：动手实验、故障案例与参考答案](03-labs-and-troubleshooting.md)
   - 从单文件脚本开始，观察目录和导入行为。

## 应该怎样学

前两册重在理解，标为“假设”或“示意”的命令不用照着执行。第三册才逐步动手。执行前先确认两件事：命令输入在哪里，成功后应该看到什么。

建议分为八次：

| 次数 | 主题 | 达标表现 |
| --- | --- | --- |
| 1 | 第一册第 1–2 章 | 分清进程、工作目录、脚本位置和 PATH |
| 2 | 第一册第 3–4 章 | 能证明正在使用哪个解释器、pip 装到哪里 |
| 3 | 第一册第 5–6 章 | 知道 import 怎样找代码，-m 怎样启动模块 |
| 4 | 第二册第 1–3 章 | 能组织一个小项目，区分代码、配置、数据 |
| 5 | 第二册第 4–6 章 | 知道哪些依赖需要记录、怎样测试与定位错误 |
| 6 | 第二册第 7–9 章 | 说清从拿到源码到运行成功，要准备哪些东西 |
| 7 | 第三册实验 1–4 | 做出可安装、可测试的命令行项目 |
| 8 | 第三册实验 5–6 | 在独立环境中安装 wheel，证明未依赖源码目录 |

一次学一部分，不必背下全部术语和参数。实验前猜结果，做完比较；猜错时回看对应解释。能说清“为什么”，比照抄命令成功更重要。

## 学习边界

需要认识变量、字符串、函数调用和缩进；第三册会解释实验中出现的少量语法。暂时不需要深入面向对象、异步或算法。

网站安全、数据库管理、GPU 等仍需各自学习。这里先教你判断项目需要哪些条件；一份依赖清单不能代替所有运行条件。

## 示例验证记录

示例此前已在本机 Windows、CPython 3.12.14 验证：6 项测试通过，wheel 制作成功。在另一个没有开发工具的环境安装后，换到源码目录外也能运行；包内文本能正常读取，输出为 21 个码点、2 行、3 个空白分隔词。

验证文件保存在 Git 忽略的 build/course-validation，没有给正式应用安装教学依赖。测试时曾遇到临时目录权限问题，改用专用临时目录后通过。尚未在第二台实体电脑或 macOS/Linux 验证。
