# Python 工程通用基础：从一段代码到可迁移项目

这是一套不依赖 GrepzzTranslate 的教材。适用于自动化脚本、数据分析、命令行工具、桌面程序和 Web 后端中的共同基础。不同领域的框架另学，但环境、导入、依赖、文件组织、测试和迁移的原理可以复用。

教材中的 Python 3.12 是实验基线，不是“所有新项目都必须用 3.12”的建议。选择其他版本前，应核对目标库、部署系统和工具支持情况。命令以 Windows PowerShell 为主，关键位置给出 macOS/Linux 对照。

## 应该怎样学

不要把教材当成命令清单。每遇到一个命令，先回答：谁执行它、从哪里执行、它读什么、它改什么、怎样验证结果。

建议分为八次：

| 次数 | 主题 | 达标表现 |
| --- | --- | --- |
| 1 | 第一册第 1–2 章 | 分清进程、工作目录、脚本位置和 PATH |
| 2 | 第一册第 3–4 章 | 能证明正在使用哪个解释器、pip 装到哪里 |
| 3 | 第一册第 5–6 章 | 能解释 import 和 python -m 的区别 |
| 4 | 第二册第 1–3 章 | 能组织一个小项目，区分代码、配置、数据 |
| 5 | 第二册第 4–6 章 | 知道哪些依赖需要记录、怎样测试与定位错误 |
| 6 | 第二册第 7–9 章 | 能描述从 Git 到部署环境的完整链路 |
| 7 | 第三册实验 1–4 | 做出可安装、可测试的命令行项目 |
| 8 | 第三册实验 5–6 | 在独立环境中安装 wheel，证明未依赖源码目录 |

读完不等于掌握。实验要先预测结果再运行，结果不符时写下“我之前错误地假设了什么”。不必背版本号和命令参数；应该掌握观察与判断的方法。

## 学习边界

需要认识变量、字符串、函数调用和缩进；第三册会解释实验中出现的少量语法。暂时不需要深入面向对象、异步或算法。

这套材料不能代替 Web 安全、数据库运维、GPU 驱动、分布式部署等专业课程；它提供理解这些主题所需的工程基础。不能仅凭同一份依赖清单承诺“任何电脑都能运行”。

## 示例验证记录

示例已在本机 Windows、CPython 3.12.14 下验证：独立开发环境可编辑安装成功，6 项测试通过，wheel 构建成功；另建未安装开发依赖的环境普通安装该 wheel，从源码目录外使用隔离模式及命令行入口均成功，包内文本资源也包含在产物中。实际输出为 21 个码点、2 行、3 个空白分隔词。

验证环境位于仓库忽略的 build/course-validation 中，没有向正式应用的虚拟环境安装教学依赖。测试期间遇到原有系统临时目录访问限制，改用本次验证专用临时目录后通过。该记录不代表已经在另一台电脑或 macOS/Linux 验证。

## 资料使用方式

正文中的案例、排错顺序和实验为本教材组织。官方资料用于核对关键行为，链接放在相关章节末尾；先学正文，再查原文。不要求同时安装所有提到的工具。当前项目文件不需要为做实验而改动。
